# Этап 0. Фундамент

**Цель этапа:** приложение запускается на Android и десктопе, подключается к локальному Workspace Host и показывает реальный репозиторий. Агента и ревью ещё нет — есть скелет, протокол и границы модулей.

**Не входит в этап:** агент, diff, инбокс, редактор, tools.

**Сквозная проверка этапа** — последняя задача (T-0.15).

## Протокол

- [x] **T-0.8 Каркас сообщений протокола** — 2д · § 8.4
  - Зависит: T-0.5
  - Готово когда: описаны сообщения запроса/ответа/событий для открытия репозитория, дерева файлов, содержимого файла, состояния хоста и ошибки доступа, у каждого сообщения перечислены поля; сериализация бинарная; есть номер версии протокола; неизвестный тип сообщения не роняет клиент, а логируется и игнорируется — тест подаёт 3 неизвестных типа подряд и клиент продолжает работу.

- [x] **T-0.9 Проверка совместимости версий протокола** — 1д · § 8.4

- [x] **T-0.10 Транспорт WebSocket с реконнектом** — 2д · § 8.4
  - Зависит: T-0.8
  - Готово когда: клиент соединяется с хостом, переживает обрыв сети и восстанавливает сессию без перезапуска приложения; после реконнекта клиент получает актуальное состояние, а не продолжает с устаревшим; повтор изменяющего запроса с тем же идентификатором не создаёт вторую правку.

- [ ] **T-0.15 Сквозная проверка: репозиторий на экране** — 1д · § 6.1, NFR-7
  - Зависит: все предыдущие задачи этапа
