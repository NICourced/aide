# Этап 1. MVP review-цикл

**Цель этапа:** пользователь формулирует задачу, агент её выполняет, результат попадает в инбокс, пользователь ревьюит по hunk'ам и принимает — включая полностью с телефона.

**Не входит в этап:** полноценный редактор (этап 2), конструктор внешних tools (этап 3), роли агентов (этап 4), удалённый хост через интернет (этап 5).

**Сквозная проверка этапа** — последняя задача (T-1.54).

## Режимы автономности

- [ ] **T-1.15 Четыре режима автономности** — 2д · FR-AGENT-1..6
  - Зависит: T-1.12, T-1.13
  - Готово когда: для каждого из четырёх режимов «Только предлагать», «Спрашивать перед изменениями», «Авто-применять безопасное», «Полный автомат с чекпоинтами» прогон на фикстуре даёт ожидаемый результат: в «Только предлагать» вызов записи не применён (хеш файла не изменился), изменение лежит в инбоксе; в «Спрашивать перед изменениями» вызов ждёт подтверждения; в «Авто-применять безопасное» изменение `safe` применено без подтверждения, `normal` — нет; в «Полном автомате» перед шагом есть снапшот; режимы переключаются в настройках, переключение во время прогона не меняет правила текущего прогона (в журнале прогона сохраняется режим старта); в интерфейсе видно, какой режим активен.

- [ ] **T-1.16 Авто-применение безопасного** — 2д · FR-AGENT-3, FR-AGENT-6, § 5.3.2
  - Зависит: T-0.7, T-1.15

- [ ] **T-1.17 Чекпоинты полного автомата** — 1д · FR-AGENT-4
  - Зависит: T-1.15, T-1.19 (вне очереди: без снапшотов чекпоинты невозможны)
  - Готово когда: в режиме полного автомата перед каждым изменяющим шагом ставится снапшот; после прогона в инбоксе виден список созданных снапшотов и возможен откат к любому.
